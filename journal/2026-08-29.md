## Current Implementation Baseline
- The supported implementation is the Rust `gvm-mcp` server; the legacy
  Python implementation and migration remnants were removed in August.
- The server is a typed MCP front end over the `rust-gvm-api` REST gateway,
  with stdio and streamable-HTTP transports.
- Authentication is stateless: inbound HTTP authorization is forwarded per
  request, with configured credentials available as a fallback.
- The full surface contains 104 tools: 81 in the default selection, 49 in
  default read-only mode, and identity tools available as an opt-in toolset.
- Reports support drill-down and asynchronous exports; target and task tools
  cover CRUD and scan lifecycle operations.
- Mock-gateway tests run without a GVM installation, while live-stack tests
  remain opt-in.
